motionx

a free mobile video editor built for velocity edits and motion graphics.

motionx combines the animation power of alight motion with the editing tools of capcut. designed with a dark interface, smooth workflow and no paid editing features.

features

motion graphics

* keyframe animation for position, scale, rotation and opacity
* custom bezier curves and velocity graphs
* motion blur, shakes, glow and zoom effects
* multiple layers and blending modes
* reusable effects and animation presets

video editing

* import and preview video clips
* trim, split, crop and merge clips
* transitions and speed ramping
* text, captions, fonts and overlays
* music, sound effects and audio controls
* color grading and visual filters

export

* frame rate options including 24, 30, 60 and 120 fps
* resolution options from 720p up to 4k where supported
* no watermark
* save projects locally
* export settings designed for smooth playback

actual export capabilities depend on device hardware, video encoding support and the implementation of each feature.

platform

* target device: iphone 14
* target operating system: ios 27
* primary interface: native-style mobile editing workspace
* development: react native and expo, with native ios video processing as needed
* distribution goal: signed ios ipa

project status

development in progress

motionx is an independent project. the initial goal is to build a functional editor, then expand its timeline, animation engine, effects and export capabilities.

principles

* free to use
* no watermark
* no subscription required
* simple and responsive interface
* project files stay on your device by default
* no unnecessary features that slow down editing
